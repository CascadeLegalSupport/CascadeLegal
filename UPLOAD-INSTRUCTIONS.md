# Upload to Josh's GitHub repository

1. Unzip this package.
2. Open https://github.com/CascadeLegalSupport/CascadeLegal
3. Choose **Add file → Upload files**.
4. Drag `index.html`, `fresh.css`, `fresh.js`, and the `assets` folder onto the upload area.
5. Enter `Publish Cascade Legal Support website` as the commit message and select **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main**, folder **/(root)**, then select **Save**.

GitHub will publish the site at:

https://cascadelegalsupport.github.io/CascadeLegal/

Do not point `www.cascadelegalsupport.com` to GitHub until Josh has reviewed and approved the published site.
